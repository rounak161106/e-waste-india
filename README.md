# E-Waste India — Electronic Waste: Where Do We Stand?

> **⚠️ NOTE: This repository constitutes a university assignment.** This is a data-driven awareness website built specifically as an academic project for the **CHE-110 Environmental Studies CA1** assessment at **Lovely Professional University (LPU)**.


## Project Info

- **Course:** CHE-110 | Environmental Studies
- **University:** Lovely Professional University
- **Academic Year:** 2025–26 | CA1 Project
- **Team:** Rounak Prasad, Tushar Kadian, Rahul Panwar

## About

This website educates visitors about the growing e-waste crisis in India and globally, featuring:
- 📊 Interactive charts (global e-waste producers, recycling rates, hidden material value)
- 🇮🇳 India-specific crisis data (Seelampur, CPCB, MeitY sources)
- ☠️ Health & environmental impact breakdowns
- 🌍 Global case studies (Japan, Germany, Ghana, Bengaluru)
- 🧠 Interactive e-waste awareness quiz
- 🎬 Documentary: *The Toxic Treasure Paradox*
- ♻️ Practical step-by-step action guide

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** + **shadcn/ui**
- **Framer Motion** (animations)
- **Recharts** (data visualisation)
